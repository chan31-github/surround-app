# Surround

An iOS app for capturing and viewing immersive photo spheres of scenic
viewpoints, built for hiking in Hong Kong.

- `docs/SPEC.md`: requirements, milestones, technical approach.
- `docs/BUILDING.md`: how to generate the Xcode project and run on a phone.
- `Packages/SurroundCore`: platform-independent logic with unit tests.
- `Surround/`: the iOS app.

Milestone 1 is a guided single-ring (cylindrical) capture stitched on
device and viewed by moving the phone. The full sphere is milestone 2.
